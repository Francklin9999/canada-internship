# Contributing to Intern Radar

Thanks for helping Canadian students and new graduates find strong opportunities sooner.

## Suggest a listing

[Open the listing suggestion form](../../issues/new?template=suggest-listing.yml) and include the company, role title, Canadian location, and application URL.

A good submission is:

- an internship, co-op, new-grad, early-career, apprenticeship, or trainee role;
- based in Canada or explicitly open to applicants working remotely from Canada;
- still accepting applications; and
- linked to the employer's application page whenever one is available.

Please submit one role per issue. Do not include personal information, referral codes, or tracking links.

## Report a correction or closed role

Use the same [listing report form](../../issues/new?template=suggest-listing.yml) with the company, role title, current listing URL, and the correction needed. Useful reports include duplicate rows, incorrect locations, expired applications, and links that no longer reach the employer's posting.

## About pull requests

The job tables are generated from automated collection and validation. Direct edits to `README.md` or `NEW_GRAD.md` will be replaced by the next refresh, so issues are the most reliable way to suggest listing changes.

Small documentation and accessibility improvements are welcome as pull requests. Keep changes focused and explain the user-facing benefit in the description.
